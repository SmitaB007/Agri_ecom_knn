# AI-Powered E-Commerce Platform for Farmers

This project is an AI-driven e-commerce platform designed to enhance the online shopping experience for farmers and agricultural businesses. It provides personalized product recommendations using machine learning techniques.

## Features

- **User-Friendly Platform:** Farmers and agricultural businesses can easily browse and purchase essential products online.
- **Personalized Recommendations:** Integrated a **K-Nearest Neighbors (KNN) recommendation system** that analyzes user purchase history to suggest relevant products.
- **Product Management:** Efficient management of product catalog and inventory.


## Tech Stack

- **Backend:** Django  
- **Machine Learning:** scikit-learn, pandas, NumPy  
- **Database:**  SQLite
- **Frontend:** Bootstrap, HTML/CSS
